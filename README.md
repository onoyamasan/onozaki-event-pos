# イベントレジ（オフライン対応PWA）

野外イベントの出店ブースで使う、**電波が無くても動くレジ**です。

## できること

- 圏外でもアプリが起動し、会計を打てる（Service Worker + IndexedDB）
- 現金会計はテンキーでお預かりを入力し、お釣りを自動計算
- PayPay会計は金額を大きく表示して確認
- 電波が戻ると、未送信の会計を自動でまとめて送信する

## 使い方

1. **事前（電波のある場所で）** — アプリを開き「取り込む」で当日のイベントを端末に保存する
2. **会場（圏外でOK）** — アプリを起動してレジを打つ。未送信件数が画面上部に出る
3. **帰社後（電波のある場所で）** — アプリを開くと自動で送信される

iPadでは Safari で開いたあと **［共有］→［ホーム画面に追加］** して、
以後はホーム画面のアイコンから起動してください。ブラウザのタブのままだと
iOS に保存領域を消される可能性があります。

## セキュリティについて

このリポジトリには画面と計算ロジックしか入っていません。
接続先URL・合言葉・業務データは一切含まれず、端末登録時に渡す
「接続コード」を持っている端末だけが実際に動作します。

## 開発メモ

- 依存ライブラリなし（素のHTML/CSS/JS）
- `sw.js` を更新したら `CACHE` の版数を必ず上げること。上げ忘れると端末に古い画面が残る
- アイコンは `make_icons.py`（標準ライブラリのみ）で生成
